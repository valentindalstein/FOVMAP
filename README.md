# FOVMAP
Fly Ommatidia Visualization, Mapping And Projection

Ommatidia orientation data from Zhao et al., “Eye Structure Shapes Neuron Function in Drosophila Motion Vision.”. By default the fly is looking in the x axis direction, its posterior anterior axis being the x axis.

Polyhedron file can be found https://dmccooey.com/polyhedra/. Polyhedron used https://dmccooey.com/polyhedra/DualGeodesicIcosahedron12.html.
